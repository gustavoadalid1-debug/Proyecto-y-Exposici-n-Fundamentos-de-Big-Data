# Datos

Ambos datasets son pequeños (< 3 MB en total) y se incluyen directamente en
este repositorio.

## `Zomato_Restaurant_Dataset.csv`
- **Formato:** CSV (datos estructurados).
- **Contenido:** 9,551 restaurantes a nivel mundial, con ciudad, coordenadas,
  tipo de cocina, calificación, votos y si ofrecen entrega a domicilio.
- **Origen:** dataset público "Zomato Restaurants" (Kaggle). Si se necesita
  descargar de nuevo: <https://www.kaggle.com/datasets/shrutimehta/zomato-restaurants-data>

## `airports.json`
- **Formato:** JSON (datos semiestructurados).
- **Contenido:** 30 aeropuertos internacionales clave, con código IATA,
  nombre, ciudad, país y coordenadas (latitud/longitud).
- **Origen:** curado manualmente por el equipo para este proyecto.

> Si en otra entrega el dataset supera el límite de GitHub (100 MB por
> archivo / recomendado <25 MB), no se debe subir directamente al
> repositorio. En su lugar, este archivo debe documentar el enlace de
> descarga y el procedimiento para obtenerlo.
